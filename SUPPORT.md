# Support

Where to take a question, in the order most likely to get you an answer.

## Documentation

| You want | Read |
|---|---|
| What passmcp checks and how to fix a finding | [passmcp's manual](https://satellion.com/passmcp/docs/) |
| How this site is built | [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) |
| Toolchain and gates | [DEVELOPMENT.md](DEVELOPMENT.md) |
| The rule every change here follows | [CONTRIBUTING.md](CONTRIBUTING.md) |

## Bugs in the site

[GitHub Issues](https://github.com/sebastienrousseau/satellion.github.io/issues),
using the templates: a wrong claim, a broken page or link, a Go module path
that does not resolve.

## Questions about passmcp

A question about passmcp itself, or a verdict it reached, belongs in
[passmcp's issues](https://github.com/sebastienrousseau/passmcp/issues).

## Security

**Do not open a public issue for a vulnerability.** Follow
[SECURITY.md](SECURITY.md).

## Response expectations

satellion.com is maintained by one person alongside other work. Issues are
read within a week; security reports follow the timeline in SECURITY.md.
There is no commercial support offering.
